# Quran Muallem 1.10.1 – Release Notes (versionCode 36)

Play Console → Release → „Versionshinweise“ (je Sprache max. 500 Zeichen). Block komplett einfügen.

**Hinweise:**
- 1.10.1: Tajwid-Beispiele starten standardmäßig mit der Wort-für-Wort-Stimme von Quran.com (dieselbe wie «استمع إلى الكلمة» bei den Fehlerkorrekturen im Mushaf); Umschalter im Leitfaden auf den gewählten Scheich (localStorage `qm.tajweed.voice`). Die jeweils andere Stimme ist der Ersatz, zuletzt der ganze Vers. Nur `TajweedGuide.tsx` und `tajweedAudio.ts` geändert.
- 1.10.0 (v35): Tajwid-Leitfaden mit Audio, neue Abschnitte, Favoriten, Tajwid-Analyzer (siehe RELEASE_NOTES_1.10.0.md).
