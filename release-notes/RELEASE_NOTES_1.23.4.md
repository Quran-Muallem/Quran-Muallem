# Quran Muallem 1.23.4 – Release Notes (versionCode 63)

Play Console → Release → „Versionshinweise“ (je Sprache max. 500 Zeichen). Block komplett einfügen.

**Hinweise:**
- `KidsMushafView.tsx`: Übersetzung nutzt `--kd-ink-soft` (vorher fest `#334155`, im Kinder-Design «Nacht» unsichtbar); aktuelles Wort mit dunkler Schrift auf der gelben Markierung; Fehlerwort als heller Chip wie Grün/Orange.
- Mikrofon im Ruhezustand ist jetzt dieselbe breite Leiste wie beim Zuhören (türkis «kidsMicStart» ↔ korallrot «kidsMicListening»), mittig über der Navigation.
- Datenschutzerklärung geprüft: nur Oberfläche geändert → Text unverändert (Stand 15.11.2026), App- und Web-Fassung neu erzeugt.
