# Quran Muallem 1.3 – Release Notes (versionCode 23)

Play Console → Release → „Versionshinweise“ (je Sprache max. 500 Zeichen). Block komplett einfügen.

**Hinweise:**
- Tafsir Ibn Kathir (Ilm Verlag) und as-Sa'di gibt es auf Deutsch nur urheberrechtlich geschützt – nicht ohne Lizenz einbauen. Die deutsche Tafsir-Gruppe erklärt das; neu ist die deutsche Rowwad-Übersetzung (QuranEnc) mit Fußnoten.
- Android-Sperrbildschirm: `@capgo/capacitor-media-session` (nach `npm install` einmal `npx cap sync android`).
- Die Adhan-Aufnahmen aus 1.2 (Qassas, Alafasy) – Nutzungsrechte weiterhin vor der Veröffentlichung bestätigen.
