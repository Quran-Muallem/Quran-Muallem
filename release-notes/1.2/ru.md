Quran Muallem 1.2
• Для каждого намаза: полный азан, только вибрация или выкл. — даже при закрытом приложении
• Голоса муэдзинов с прослушиванием, один для всех или для каждого намаза; Фаджр всегда с «ас-саляту хайрун мин ан-наум»
• Пауза и продолжение чтения без потери цветов и позиции
• Переводы и тафсиры по языкам (Ибн Касир, ас-Саади, аль-Куртуби, ат-Табари …) со скачиванием
• Хадисы: названия книг Бухари и Муслима на арабском
